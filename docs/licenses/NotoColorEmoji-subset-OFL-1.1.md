# Noto Color Emoji subset

`designsystem/src/commonMain/composeResources/font/quata_feed_emoji_subset.ttf` is a 7,208-byte
subset of [Noto Color Emoji](https://github.com/googlefonts/noto-emoji), containing only the
five feed glyphs used by Quata: U+1F6A8, U+1F525, U+1F4CD, U+1F4DD, and U+1F4C4 (plus U+FE0F).

`designsystem/src/commonMain/composeResources/font/quata_header_logo_q_subset.ttf` is a
10,820-byte Roboto Flex subset instantiated at weight 900, containing U+0051 and U+0308 only.
