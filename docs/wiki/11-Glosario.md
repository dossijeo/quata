# Glosario

**Adaptador de plataforma**  
Implementación Android, browser o iOS de un servicio del sistema ofrecido a una raíz común.

**Android de referencia**  
Aplicación publicada cuyo comportamiento se conserva durante la migración.

**Backend real**  
Contrato remoto vigente de Supabase, WordPress u otro servicio, no una respuesta local o simulada.

**Candidato**  
Commit de una PR draft sometido a validación. No forma parte de `main`.

**Common root / raíz común**  
Composable de nivel de pantalla o flujo que contiene la experiencia completa compartida.

**Compose/Wasm**  
Aplicación Web compilada desde Kotlin a WebAssembly y renderizada con Compose Multiplatform.

**Contrato de producto**  
Comportamiento visible: reglas, estados, navegación, acciones y efectos persistentes.

**Evidencia exacta**  
Resultado de compilación, ejecución o captura identificado por commit SHA.

**GO**  
Aprobación de una pantalla que ha superado todos los gates requeridos para el SHA exacto.

**HOLD**  
Estado pendiente por falta de entorno o evidencia; no es una aprobación parcial.

**Host**  
Contenedor Android, Web o iOS que monta Compose y proporciona servicios de plataforma.

**NO-GO**  
Rechazo justificado por un incumplimiento funcional, visual, técnico u operativo.

**Port**  
Aplicación Web o iOS que reutiliza el producto común, no una reimplementación independiente.

**RLS**  
Row Level Security de PostgreSQL/Supabase.

**Shell público**  
Cabecera, navegación y contenido visibles sin sesión en las rutas públicas.

**Static GO**  
Expresión histórica para una revisión de código/compilación. No sustituye el GO funcional completo y queda invalidada al cambiar el SHA.

**Worktree**  
Checkout Git aislado utilizado por un agente o una validación.
